Git and Github

Git'as - kodo versijavimo programa.
GitHub'as - versijoto kodo talpykla internete.

Git komandos

  • init - sukurti git repozitoriją dabartiniame aplankale
  • status - pateikia git repozitorijos dabartinę informaciją
  • add - prideda nurodytus failus prie commitinimui paruoštų failų (stage area)
