Git and Github

Git'as - kodo versijavimo programa.
GitHub'as - versijoto kodo talpykla internete.

Git komandos

  • init - sukurti git repozitoriją dabartiniame aplankale
  • status - pateikia git repozitorijos dabartinę informaciją
  • add - prideda nurodytus failus prie commitinimui paruoštų failų (stage area)
  • rm --cashed or restore --staged - išima nurodytus failus iš stage'inimo zonos (unstage'ina)
  • commit -m "žinutė" - sukuria kodo versiją iš stage'intų failų ir prideda žinutę pie pakitimus
  • restore - sugrąžina nurodytą/us failą/us į pradinę būseną ( jeigu tie failai nebuvo add'inti į stage zoną)
  • push - nusiunčia lokalios repozitorijos commitus į išorinę repozitoriją
  • pull - atsiunčia išorinės repozitorijos pakitimus į lokalią repozitoriją
  • log - išveda commitų sąrašą
  • clone - nuklonuoja nurodytą projektą į dabartinį aplankalą
  • checkout commitID|brancName - pereinama į nurodytą kodo versiją arba kitą šaką
  • branch naujosSakosPav - sukuriama nauja šaka
  • ...

Branch protection rules

Vienas svarbiausių šakų apsaugos taisyklių yra "Pull request" (bandymas vienos šakos commit'us sukelti į kitą šaką (merge))
Pull Request taisyklės viduje dar reikėtų suteikti "Request approvals" nustatymą, kuris reikalauja, kad nurodytas kiekis kitų projekto dalyvių patvirtintų tą Pull Request'ą norint, kad šakos būtų apjungtos.
